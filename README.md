# Casa Firma 

Create a complete, premium, luxury and responsive website for CASA FIRMA, a maison d’hôtes / private holiday accommodation in Tazarka, Tunisia.

This is a real business website DEMO intended to be presented to the property owner.

The website must look like a professional boutique Mediterranean guesthouse website, NOT like a generic AI-generated template.

IMPORTANT:
- Build the actual working website.
- Make it fully responsive for desktop, tablet and mobile.
- Prioritize mobile usability.
- The main conversion goal is: Visitor → Explore property → Choose accommodation → WhatsApp/contact → Booking.
- Do NOT create fake reviews.
- Do NOT invent prices.
- Do NOT invent opening hours.
- Do NOT invent awards or certifications.
- Do NOT invent services that are not listed below.
- If information is missing, omit it or use a clearly marked placeholder.
- Use temporary high-quality Mediterranean accommodation photography that can later be replaced with the property's real Instagram photos.
